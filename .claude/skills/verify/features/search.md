# 搜索

访客在列表上方的搜索框打字，列表只留下句子内容或说话人含有关键字的名句（不分大小写），命中的字加上着重号；没有结果时显示空状态。关键字存在网址的 `q`，可以跟出处 / 标签筛选一起用。

## Sub-features

- `search-content` 关键字比对句子内容。
- `search-speaker` 关键字比对说话人。
- `search-highlight` 命中的字用 `<em>` 着重号标出（内容与说话人都会）。
- `search-empty` 没有结果时显示「没有符合的名句。」。
- `search-combined` 搜索 + 出处 / 标签筛选取交集。
- `search-clear` 清空搜索框，或按「清除筛选」，回到全部。

## How to get to it (user POV)

- 中间上方的搜索框（placeholder「搜索句子内容或说话的人」）。
- 网址 `/?q=孔子`。

## Driving it with lines.mjs drive

Preconditions:

- 基准状态。孔子说了 2 句（论语），「明天」只出现在麦克白那一句，「小林」说了 2 句。

- **比对内容。** `getByRole('searchbox', { name: '搜索' }).fill('明天')`。等 `getByText('1 句', { exact: true })`；网址含 `q=`；那一句里有 `em` 元素，文字是「明天」。
- **比对说话人。** 改成 `孔子`。显示 `2 句`；出处行里的「孔子」有着重号。
- **组合筛选。** 保持 `小林`（2 句），再点左栏 `#时间 2`。显示 `1 句`（「时间不会让事情变好…」）。
- **没有结果。** 改成 `火山`。显示 `0 句` 与「没有符合的名句。」。
- **清除。** 点「清除筛选」。搜索框变空，显示 `12 句`。
- **网址入口。** `page.goto('/?q=孔子')`。搜索框的值是「孔子」，显示 `2 句`。
- **证据。** 命中、组合、空状态各 `shot()`；用 `api('/api/quotes?q=孔子')` 读回长度 2。

## Gotchas

- 有 200ms debounce：`fill` 之后要等「N 句」变化，不要立刻断言，也不要用固定 sleep。
- 只搜内容与说话人，不搜出处名称、标签、出处细节、笔记：搜「论语」是 0 句，这是预期行为。
- 前后空白会被忽略；全是空白等于没有搜索。
- 用 `fill` 输入，不要逐字 `type` 中文，避免输入法相关的事件差异。
