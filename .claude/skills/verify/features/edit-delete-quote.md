# 编辑与删除名句

站长在管理页（`/admin`）点列表的一句，右栏从新增表单变成这一句预先填好的编辑表单（标题「编辑名句」，旁边有「新增另一句」回到空白表单）；储存后留在这一句的编辑表单，列表与侧栏立刻更新。删除要按两次（「删除」→「确定删除？」），删掉后右栏回到新增表单，列表与侧栏句数减少。没有 dialog，也没有「取消」。

## Sub-features

- `edit-open` 点列表一句 → 右栏变编辑表单，栏位预先填好，该句在列表里是选中状态。
- `edit-new-another` 「新增另一句」回到空白的新增表单，列表不再有选中的句子。
- `edit-save` 改内容、出处、标签后储存，留在这一句的编辑表单，列表与侧栏更新。
- `edit-validation` 清空内容后储存显示「请输入句子内容」。
- `delete-confirm` 第一次按「删除」只变成「确定删除？」，失焦就恢复；第二次才删。
- `delete-done` 删除后右栏回到新增表单，句数减一。

## How to get to it (user POV)

- 在 `/admin` 点列表的一句。

## Driving it with lines.mjs drive

Preconditions:

- 基准状态。用 id 4「学而不思则罔，思而不学则殆。」（孔子，论语，#学习）。

- **打开编辑。** `page.goto('/admin')`，点 `getByRole('button', { name: /学而不思则罔/ })`。看到标题「编辑名句」与按钮 `新增另一句`；`getByLabel('句子内容')` 的值是原句；有 `'移除标签 学习'`；该列表项 `aria-current="true"`；没有 `取消` 按钮。
- **新增另一句。** 点 `新增另一句`。标题变「新增名句」，`句子内容` 是空的且有焦点，没有 `删除` 按钮，列表项不再 `aria-current`。再点那一句回到编辑。
- **验证错误。** 清空句子内容，点 `储存`。看到「请输入句子内容」。
- **储存。** 内容改成 `学而不思则罔（已编辑）`，加标签 `'+ 人生'`，点 `储存`。右栏仍是这一句的编辑表单（标题「编辑名句」、内容是新值）；列表那一列也更新；侧栏 `#人生 7`。
- **第二个视角。** `api('/api/quotes/4')`：`content` 是新值，标签两个；`page.goto('/')` 后点这一句，详细是新内容。
- **删除确认。** 点 `删除`。按钮变成 `确定删除？`；按 `Tab` 让它失焦，又变回 `删除`，资料还在。
- **删除。** 点 `删除` 再点 `确定删除？`。右栏回到「新增名句」表单；句数变 11；`api('/api/quotes/4')` 回 `null`（404）。
- **证据。** 编辑表单、储存后的列表、确定删除、删除后的列表各 `shot()`。

## Gotchas

- 「确定删除？」靠 blur 恢复：两次点击中间不要点别的地方，否则只会恢复成「删除」。
- 删除只删名句，出处与标签保留：删掉论语一句后侧栏「论语 1」仍在。
- 编辑与删除都会写入 D1：跑完要基准状态就 `down` 再 `up`。
- 储存编辑不会有「已储存」的提示，要靠列表上的新内容判断。
- 右栏切到别句或「新增另一句」时表单会卸载，没储存的修改直接丢掉，不会提示。
