# 编辑与删除名句

站长在右栏看一句名句时按「编辑名句」，右栏换成预先填好的表单；储存后回到详细并显示新内容，取消则不改。删除要按两次（「删除」→「确定删除？」），删掉后右栏回到空白提示，列表与侧栏句数减少。

## Sub-features

- `edit-open` 详细栏的「编辑名句」把右栏换成表单，栏位预先填好。
- `edit-save` 改内容、出处、标签后储存，回到详细显示新值。
- `edit-cancel` 「取消」回到详细，不写入。
- `edit-validation` 清空内容后储存显示「请输入句子内容」。
- `delete-confirm` 第一次按「删除」只变成「确定删除？」，失焦就恢复；第二次才删。
- `delete-done` 删除后右栏回到空白提示，句数减一。

## How to get to it (user POV)

- 点列表的一句 → 右栏「编辑名句」。

## Driving it with lines.mjs drive

Preconditions:

- 基准状态。用 id 4「学而不思则罔，思而不学则殆。」（孔子，论语，#学习）。

- **打开编辑。** 点 `getByRole('button', { name: /学而不思则罔/ })` → `getByRole('button', { name: '编辑名句' })`。看到标题「编辑名句」；`getByLabel('句子内容')` 的值是原句；有 `'移除标签 学习'`。
- **取消。** 改内容后点 `取消`。回到详细，`blockquote` 仍是原句；`api('/api/quotes/4')` 的 `content` 没变。
- **验证错误。** 再进编辑，清空句子内容，点 `储存`。看到「请输入句子内容」。
- **储存。** 内容改成 `学而不思则罔（已编辑）`，加标签 `'+ 人生'`，点 `储存`。回到详细，`blockquote` 含新内容，标签有 `#学习` 与 `#人生`；列表那一列也更新；侧栏 `#人生 7`。
- **第二个视角。** `api('/api/quotes/4')`：`content` 是新值，标签两个；`page.reload()` 后再点这一句仍是新内容。
- **删除确认。** 进编辑，点 `删除`。按钮变成 `确定删除？`；按 `Tab` 让它失焦，又变回 `删除`，资料还在。
- **删除。** 点 `删除` 再点 `确定删除？`。右栏回到「点中间的一句…」；句数变 11；`api('/api/quotes/4')` 回 `null`（404）。
- **证据。** 编辑表单、储存后的详细、确定删除、删除后的列表各 `shot()`。

## Gotchas

- 「确定删除？」靠 blur 恢复：两次点击中间不要点别的地方，否则只会恢复成「删除」。
- 删除只删名句，出处与标签保留：删掉论语一句后侧栏「论语 1」仍在。
- 编辑与删除都会写入 D1：跑完要基准状态就 `down` 再 `up`。
- 右栏切到别句时表单会卸载，没储存的修改直接丢掉，不会提示。
