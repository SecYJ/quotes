# E2E 测试：用 Playwright 测阅览页

Status: needs-triage

测试写在 `tests/e2e/`，每个 `test()` 的名称以这里的 ID 开头。

## 目标

阅览页的行为（docs/init.md「功能」1–6）每一项都有一个写死期望值的测试，改 `src/` 之后跑 `pnpm test:e2e` 就知道有没有坏。现在 `shots.mjs` 的检查是从页面上读期望值，真实资料只有 5 句、没有说话人与英文标签，很多行为测不到。

## 待确认的决定（先用括号里的预设）

1. **测试资料**：用固定的测试资料（`tests/e2e/fixtures/sources/*.yaml`），另外 build 一份到 `dist-e2e/`。需要 `content.config.ts` 的 glob `base` 可以用环境变数换掉（预设仍是 `./src/content/sources`）。真实资料不另写测试，由 `shots.mjs` 对 `dist/` 截图时顺便检查。
2. **shots.mjs**：行为检查搬进测试，`shots.mjs` 只留截图与「没有横向捲动」。
3. **只有中文**：网站目前不支援英文，测试资料与案例都不放英文（不测英文大小写）。
4. **浏览器**：Chromium 桌机（1440×900）+ Chromium 手机（390×844）两个 project。
5. **CI**：只在本机跑，写进 docs/verification.md。

## 测试案例

每个测试都检查没有 `console` error 与 `pageerror`（写在共用 fixture 里，不另列）。

### A. 载入与排版（功能 1）

| ID | 步骤 | 期望 |
| --- | --- | --- |
| A-01 | 打开 `/` | 6 句全部显示；顺序 A→F |
| A-02 | 打开 `/` | `.lead` 只有 A；`.side` 是 B、C、D；`.rest` 是 E、F |
| A-03 | 打开 `/` | 刊头写「6 句 · 4 个出处」与「最后写下 2026 年 11 月 1 日」 |
| A-04 | 看 D | 说话人「哈姆雷特」、出处「《哈姆雷特》」、出处细节「第三幕第一场」、笔记都显示；日期「9月1日」与「2026」 |
| A-05 | 看 A、F | 出处「朋友聊天」「网络段子」没有书名号；没有说话人时不出现「·」 |
| A-06 | 看索引 | 标签依次数排：全部、人生 3、职场 2、爱情 2、…；「全部」是 `aria-current`；索引里没有出处清单 |
| A-07 | 看状态列 | 没筛选时状态列隐藏 |
