# 05: 快速新增

**What to build:** 站长在管理页想到一句就能最快记下来：在表单任何一栏按 Enter 就储存；内容和笔记要换行按 Shift+Enter；中文输入法选字时的 Enter 只是选字。储存时，标签框里还没变成标签的文字会依逗号（`,` / `，`）拆开一起存进去，所以只有一个标签时打完直接按 Enter 就好。新增表单预先选好上一次储存时用的出处（只记在这台浏览器，那个出处不存在了就留空）。储存成功后表单清空、出处仍预选、光标回到内容栏，新句子出现在列表最上面。写入失败时表单内容保留并显示表单层级的错误；Access 登入过期时显示「登入已过期，请重新登入后再储存一次」。见 [spec](../spec.md)「表单行为」。

**Blocked by:** 02, 03, 04

**Status:** ready-for-agent

- [ ] 在内容、说话人、出处细节、标签、笔记任何一栏按 Enter 都会储存（出处下拉框展开时的 Enter 仍是选取）
- [ ] Shift+Enter 在内容与笔记里换行；输入法组字时的 Enter 不储存
- [ ] 标签框里未完成的文字在储存时成为标签；「爱情，人生」拆成两个
- [ ] 只有未完成的文字、没有其他标签时，不会被「请至少加一个标签」挡下
- [ ] 新增表单预选上次储存用的出处；该出处被删除或合并掉后留空；浏览器储存不可用时也能正常运作
- [ ] 储存后表单清空、出处预选、光标在内容栏
- [ ] 服务器错误、Access 过期（回应不是 JSON 或被导向）时，表单不清空，显示对应的中文讯息，列表没有出现未成功的句子
- [ ] `pnpm fmt`、`pnpm lint`、`pnpm typecheck` 通过；Playwright 跑过上述流程（含连续新增两句同一出处），无 console 错误
