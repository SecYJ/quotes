# 03: 标签规则：至少一个，忽略大小写

**What to build:** 每句名句至少要有一个标签：站长在表单里没有任何标签就储存，会在标签栏看到「请至少加一个标签」，内容不会消失；API 也同样拒绝。标签名称比较时忽略头尾空白与英文大小写：已有「Love」时输入「love」，会挂到「Love」上并保留「Love」的写法，同一次输入的「love」「Love」只算一个；数据库层也保证不会出现只差大小写的两个标签。见 [spec](../spec.md)「数据库」「API」与 GLOSSARY.md 的「标签」。
