# 08: 出处分页

**What to build:** 管理页的「出处」分页：一张表格列出所有出处（类型、名称、句数，0 句的也列出）。第一行是新增：选类型、打名称按 Enter；与已有出处完全相同时不会多出一列，而是标示出已有的那一列。点名称就地改名或改类型，Enter 储存、Esc 取消；改成跟另一个已有出处完全相同（同类型、同名称，大小写不同算不同）就是合并——按钮先变成「确定合并？」并说明有几句会并过去，再按一次才把名句改挂过去、原出处消失；只改大小写且没有冲突就只是改名。0 句的出处有「删除」，按两次确认；有名句的出处没有删除按钮。见 [spec](../spec.md)「API」与 GLOSSARY.md 的「合并」。

**Blocked by:** 02, 04, 06

**Status:** ready-for-agent

- [ ] 合并在同一个 transaction 完成

- [ ] 操作后，名句分页的出处、侧栏、句数与阅览页都反映结果
