# 04: 出处规则：不重复，可以打字搜索

**What to build:** 同一出处类型下，名称完全相同（只忽略头尾空白，大小写不同算不同）就是同一个出处，数据库层保证不重复。站长新增一个已存在的出处时，直接沿用已有的那个，不报错、不打断。表单的出处栏改成可以打字搜索的下拉框：按类型分组过滤已有出处；没有完全相同的出处时出现「新增『打的字』」，选了之后就地选择出处类型，不再有「选择已有 / 新增出处」两种模式的切换。见 [spec](../spec.md)「数据库」「API」「表单行为」与 GLOSSARY.md 的「出处」。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 一个 migration：出处 `(类型, 名称)` 唯一，区分大小写；套用到本地 D1（必要时先重跑 seed）
- [ ] 新增出处：已有完全相同的 → 200 回传已有的；只差大小写或类型不同 → 201 新建
- [ ] 出处栏打字即过滤（按类型分组）；方向键与 Enter 可选取
- [ ] 打的名称没有完全相同的出处 → 出现「新增『…』」，选择类型后储存名句时一起建立
- [ ] 新增的出处与已有的完全相同时，名句挂到已有的出处，出处列表没有多出一笔
- [ ] API 测试脚本补上上述案例并全部通过
- [ ] `pnpm fmt`、`pnpm lint`、`pnpm typecheck` 通过；Playwright 跑过过滤、选取、就地新增、同名沿用，无 console 错误
