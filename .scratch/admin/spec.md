# Spec：阅览页接真 API + 管理页

用语依 [GLOSSARY.md](../../GLOSSARY.md)：名句、内容、出处、出处类型、出处细节、说话人、笔记、标签、合并、站长、访客、阅览页、管理页。

## Problem Statement

站长目前没有地方真正写入名句：阅览页接的是浏览器里的假资料，管理页还不存在。站长想在看剧、读书、想到一句话时，回到电脑前用最少的步骤记下来，不想在弹出视窗和模式切换之间来回。

资料一多，出处和标签难免会有错字、类型选错，或两个标签意思重复（「工作」与「职场」），现在没有任何办法整理它们。

规则也有缺口：同一个出处可以被重复建立；标签「Love」与「love」会变成两个；名句可以没有标签。

## Solution

- **阅览页**改接真正的 API，任何人都能看。筛选侧栏只列出有名句的出处与标签，角落有「登入」按钮通往管理页。
- **管理页**（`/admin`，受 Cloudflare Access 保护）分成「名句 / 出处 / 标签」三个分页。所有操作都直接在画面上完成，不跳出视窗：
  - 名句分页：与阅览页相同的三栏。右栏预设就是空白的新增表单，按 Enter 储存后清空，可以马上记下一句。
  - 出处 / 标签分页：一张表格，第一行就是新增。名称点一下就能改，改成跟另一个已有的一样就是合并。
- 规则收紧：
  - 每句名句至少一个标签；
  - 同一出处类型下，出处名称不能重复（区分大小写）；
  - 标签名称忽略英文大小写。

## User Stories

### 访客（阅览页）

1. 身为访客，我想不用登入就看到所有名句，这样可以随意翻看。
2. 身为访客，我想看到每句名句的内容、说话人、出处与出处细节、笔记和标签，这样能知道这句话的来龙去脉。
3. 身为访客，我想按出处筛选，这样能看某部剧记过的所有句子。
4. 身为访客，我想按标签筛选，这样能看某个主题的句子。
5. 身为访客，我想用关键字搜索内容与说话人，这样能找回记得一半的句子。
6. 身为访客，我想同时套用出处、标签与关键字，这样能缩小范围。
7. 身为访客，我希望筛选侧栏只出现至少有一句名句的出处与标签，这样不会点进空的结果。
8. 身为访客，我想看到每个出处与标签有几句，这样知道哪些内容比较多。
9. 身为访客，我在阅览页看不到任何新增、编辑、删除的按钮，这样画面只专心在阅读。
10. 身为访客，我点了「登入」会被 Cloudflare 挡下来，不会看到任何写入功能或资料错误。
11. 身为访客，我重新整理或分享网址时，筛选与搜索条件会保留，这样别人打开看到同样的结果。

### 站长：进出管理页

12. 身为站长，我想在阅览页点「登入」就进到管理页，这样不用记网址。
13. 身为站长，我想登入交给 Cloudflare Access，这样 app 不需要自己的帐号密码。
14. 身为站长，我想在管理页按「登出」后回到阅览页。
15. 身为站长，我想用分页在名句、出处、标签之间切换。每个分页有自己的网址，重新整理后仍停在同一个分页。
16. 身为站长，我在管理页的名句分页也能用跟阅览页相同的筛选与搜索，这样能找到要编辑的句子。

### 站长：新增名句

17. 身为站长，我一打开管理页，右栏就是空白的新增表单、光标在内容栏，这样想到就能直接打字。
18. 身为站长，我想只填内容、出处和一个标签就能储存，其他栏位都可以不填。
19. 身为站长，我想按 Enter 就储存，不管光标在哪一栏，这样最快。
20. 身为站长，我在内容或笔记里需要换行时按 Shift+Enter。
21. 身为站长，我用中文输入法选字时按的 Enter 只是选字，不会意外储存。
22. 身为站长，我在标签框打了字、还没变成标签就按 Enter，那段文字也会成为标签一起储存。
23. 身为站长，我想用逗号（`,` 或 `，`）一次加好几个标签，或点已有的标签加入。
24. 身为站长，我想在出处栏打字就过滤已有的出处，这样不用在长清单里找。
25. 身为站长，我打的出处名称不存在时，可以直接选「新增『这个名称』」再选出处类型，不用切换到另一种模式。
26. 身为站长，我新增的出处若跟已有的完全相同（同类型、同名称），就直接沿用已有的那个，不会产生重复，也不会报错打断我。
27. 身为站长，新增表单会预先选好我上一次储存时用的出处，这样连续记同一部剧的句子时不用每次重选。
28. 身为站长，储存成功后表单清空（出处仍预先选好），新的句子出现在列表最上面，我可以马上记下一句。
29. 身为站长，我漏填内容、出处或标签时，看到对应栏位的错误提示，已打的内容不会消失。
30. 身为站长，我输入的标签只是大小写跟已有的不同（「love」与「Love」）时，会挂到已有的标签上，显示时保留原本的写法。

### 站长：编辑与删除名句

31. 身为站长，我想点中间列表的某一句，右栏就变成它的编辑表单，这样能直接改。
32. 身为站长，我想在编辑时一键回到「新增另一句」的空白表单。
33. 身为站长，我储存编辑后，列表、筛选侧栏的句数和阅览页都反映新的内容。
34. 身为站长，我编辑时把所有标签都拿掉会被挡下来，并提示至少要一个标签。
35. 身为站长，我想删除一句名句时按两次（「删除」→「确定删除？」），这样不会误删；按钮失去焦点就取消确认。
36. 身为站长，删除后右栏回到空白的新增表单。

### 站长：管理出处

37. 身为站长，我想看到所有出处的表格：类型、名称、句数，0 句的出处也要列出。
38. 身为站长，我想在表格第一行选类型、打名称，按 Enter 就新增出处。
39. 身为站长，我新增的出处已存在时，不会多出一列，而是标示出已有的那一列。
40. 身为站长，我想点名称就直接改名、改类型，按 Enter 储存，按 Esc 取消。
41. 身为站长，我把出处改成跟另一个已有的完全相同时，按钮先变成「确定合并？」，再按一次才把它的名句全部并到另一个出处，原本的出处消失。
42. 身为站长，我只改了大小写（「friends」→「Friends」），而且没有另一个同名出处时，这只是改名，不是合并。
43. 身为站长，我想删除 0 句的出处（按两次确认）。
44. 身为站长，有名句的出处没有删除按钮，要用合并来清掉它。

### 站长：管理标签

45. 身为站长，我想看到所有标签的表格：名称、句数，0 句的标签也要列出。
46. 身为站长，我想先单独建立一个还没有名句用到的标签，之后新增名句时就可以直接点选。
47. 身为站长，我新增的标签只是大小写跟已有的不同时，不会多出一个，而是标示出已有的那一个。
48. 身为站长，我想点标签名称直接改名，按 Enter 储存。
49. 身为站长，我把标签改名成另一个已有标签的名称（忽略大小写）时，先确认「『工作』的 3 句会并入『职场』」，再执行合并。
50. 身为站长，合并时如果某句名句同时有这两个标签，合并后它只留下一个，不会重复。
51. 身为站长，我只改了标签的大小写时，这只是改名，显示的写法跟着改。
52. 身为站长，我想删除 0 句的标签（按两次确认），例如建错字的「爱请」。
53. 身为站长，有名句的标签没有删除按钮，要用合并来清掉它。

### 站长：出错时

54. 身为站长，我的 Access 登入过期时按储存，表单不会清空、内容保留，并提示我重新登入后再储存一次。
55. 身为站长，服务器出错时我看到中文的错误讯息，已经打的内容不会消失。
56. 身为站长，我的写入失败时，列表不会显示成好像已经成功的样子。

### 站长：本地开发

57. 身为站长（也是开发者），我想用一个指令把固定的范例资料灌进本地 D1，这样画面和浏览器测试都有一样的起点。

## Implementation Decisions

### 数据库（一个新的 migration）
- 出处：`(type, title)` 唯一，区分大小写。头尾空白在 API 写入前就去掉。
- 标签：名称唯一，且忽略英文大小写。SQLite 的 `NOCASE` 只折叠 ASCII 字母，正好对应「英文大小写」。查「这些名称对应哪些标签」时也要忽略大小写。
- 「名句至少一个标签」由 API 的 zod 验证保证，数据库不另外加约束。
- 本地 D1 现有资料可能违反新的唯一约束。migration 前先用 seed 指令重置本地资料，不写资料修补逻辑（还没有远端资料）。

### API（在阶段 3 的路由上增补）
`Source`、`Tag` 的回传加上 `quoteCount`。阅览页和管理页都用它显示句数，侧栏不再为了算句数而抓全部名句。

| Method | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/sources`、`/api/tags` | 回传全部（含 0 句），附 `quoteCount`；阅览页在前端过滤掉 0 句的 |
| POST / PUT | `/api/admin/quotes`、`/api/admin/quotes/:id` | `tags` 去掉空白、忽略大小写去重后至少要有一个，否则 400「请至少加一个标签」 |
| POST | `/api/admin/sources` | 已有完全相同的出处 → 200，回传已有的；否则 201 |
| PUT | `/api/admin/sources/:id` | Body `{ type, title, merge?: boolean }`。改成跟**另一个**出处完全相同时：`merge` 不是 `true` → 409 `{ error, conflict: Source }`；是 `true` → 名句改挂到那个出处、删除原出处，回传那个出处。没有跟别的出处冲突就是一般的改名 / 改类型 |
| DELETE | `/api/admin/sources/:id` | 0 句 → 204；有名句 → 409；不存在 → 404 |
| POST | `/api/admin/tags` | Body `{ name }`。已有（忽略大小写）→ 200，回传已有的；否则 201 |
| PUT | `/api/admin/tags/:id` | Body `{ name, merge?: boolean }`。名称（忽略大小写）等于**另一个**标签时：`merge` 不是 `true` → 409 `{ error, conflict: Tag }`；是 `true` → 合并（两个标签都有的名句只留一笔关联），删除原标签。等于自己（只改大小写）→ 只改写法 |
| DELETE | `/api/admin/tags/:id` | 0 句 → 204；有名句 → 409；不存在 → 404 |

- 合并在一个 `db.batch`（D1 的 transaction）里完成，不会只合并一半。
- 前端在使用者确认前，先用已载入的清单判断这次会不会变成合并，好显示「确定合并？」。server 端的 409 是最后防线，不依赖前端的判断。
- 所有 `/api/admin/*` 维持 Access 边缘保护加上 Worker 验证 JWT（`requireAccess`），不变。

### 页面与路由
- 阅览页 `/`：沿用现有三栏，拿掉所有写入元件（新增按钮、新增 dialog、编辑 / 删除），右栏只显示详细内容；角落加「登入」，连到 `/admin`。
- 管理页 `/admin`（名句）、`/admin/sources`、`/admin/tags`：上方有三个分页和「登出」。登出导向 Cloudflare Access 的登出网址，之后回到 `/`。
- 名句分页与阅览页**共用**同一套侧栏、搜索、列表和详细元件，筛选的 search params 也跟阅览页一致。
- 名句分页的右栏只有两种状态：「新增」（预设）或「编辑某一句」，不再有 dialog。
- Cloudflare Access 保护的路径维持 init.md 列出的 `/admin`、`/admin/*`、`/api/admin/*`。

### 表单行为
- Enter 储存；Shift+Enter 在多行栏位换行；输入法组字（`isComposing`）时按 Enter 不储存。
- 储存时把标签框里还没完成的文字依逗号拆开，并入标签。
- 出处栏改成可以搜索的下拉框（combobox）：按类型分组过滤已有出处；没有完全相同的出处时，提供「新增『…』」并就地选择类型。取代现在的 Select 加「新增出处」模式切换。
- 上次储存用的出处 id 存在 `localStorage`，读写都包 try/catch；那个出处已经不存在时就留空。
- 写入失败时（包括 Access 过期导致回应不是 JSON 或被导向）显示表单层级的错误，不清空表单。Access 过期的讯息是「登入已过期，请重新登入后再储存一次」。

### 资料流
- 读写都用 Hono RPC client 加 TanStack Query。写入成功后，让名句列表、出处、标签的查询失效重抓，句数和侧栏会一起更新。不做 optimistic update。
- 删除假 API 和它的失败开关。范例资料改成本地 D1 的 seed，用 `db:seed:local` 指令写入，写入前会先清空本地资料。

## Testing Decisions

好的测试只看外部行为：送出 HTTP 请求，看回应和之后读到的资料；或在浏览器里操作，看画面。不检查函式内部，也不检查 SQL 本身。

有两个测试接缝（seam），都沿用现有的做法，不新增测试框架：

1. **HTTP API**（`pnpm dev` 启动的 Worker 加本地 D1）：沿用阶段 3 放在 scratchpad 的 API 测试脚本，补上这些项目：
   - 出处同名时回传已有的那个（大小写不同视为不同出处）；
   - 标签忽略大小写，沿用已有的；只改大小写时只改写法；
   - 合并：没带 `merge` 回 409，带了才合并；名句改挂、原项目消失、重复的关联只留一笔；
   - 删除：0 句回 204，有名句回 409；
   - 名句没有标签回 400；
   - `quoteCount` 正确；
   - 没有通过 Access 时，所有新的写入路由都回 403。
2. **浏览器**（Playwright，3440×1300，依 docs/verification.md）：
   - 阅览页：没有任何写入元件；0 句的出处和标签不出现在侧栏；「登入」连到 `/admin`；
   - 管理页名句分页：Enter 储存、Shift+Enter 换行、未完成的标签被并入、逗号拆标签、预选上次的出处、出处 combobox 的新增与沿用、验证错误、编辑、两次确认的删除；
   - 出处 / 标签分页：新增、就地改名、合并确认、删除 0 句的项目；
   - 浅色 / 深色模式都要测，且没有 console 错误。

## Out of Scope

- 手机版（只支援 3440×1440 desktop）。
- 没有出处的名句；把说话人变成独立的对象。
- 直接删除有名句的出处或标签（只能合并）。
- 批次操作、复原（undo）、修改历史。
- 搜索的 `LIKE` 跳脱 `%` / `_`、分页载入。
- 部署、远端 D1、Cloudflare Access 的 dashboard 设定（阶段 5）。
