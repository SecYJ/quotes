# Specs：quotes-ui

## 目标
先把第一版的 UI 做出来，用**假数据**在浏览器里看到实际效果，确认版面后才做数据库与 API。

依据：[overview.md](../../../overview.md) 的第一版功能。

## 范围

**包含**
- 名句列表：显示句子内容、谁说的、出处与出处细节、标签、笔记。
- 新增 / 编辑 / 删除名句。
  - 出处：选择已有出处，或当场新增（类型 + 名称）。
  - 标签：可加多个；可选已有标签，也可输入新标签。
- 按出处筛选、按标签筛选。
- 关键字搜索（句子内容、谁说的）。
- 三个版面设计，各在一个 git worktree 里，可同时 preview 比较。

**不包含**
- 数据库、API、部署（之后另开 feature）。
- 手机 / 平板版面。
- overview.md 未列出的功能。

## 目标屏幕
- ASUS PG34WCDM，3440×1440，Windows 缩放 100%。
- 浏览器可用视窗约 **3440 × 1300 px**。只需在这个尺寸下好看，不做 responsive。

## 数据（假数据）
字段与 [init.md](../../../init.md) 的数据结构一致，之后换成真 API 时 UI 不需要改：

| 资料 | 字段 |
| --- | --- |
| 出处 | id、类型（戏剧 / 书 / 现实生活 / 其他）、名称、建立时间 |
| 名句 | id、句子内容（必填）、谁说的、出处、出处细节、笔记、标签、建立 / 更新时间 |
| 标签 | id、名称（不可重复） |

- 资料存在浏览器内存，重新整理页面后回到预设的范例资料。
- 范例资料约 12 句，涵盖四种出处类型、多个标签，并包含一句很长的句子，用来检查排版。

## 行为

| 项目 | 规则 |
| --- | --- |
| 列表排序 | 依建立时间，新的在前 |
| 搜索 | 不分大小写，比对句子内容与谁说的，输入时即时筛选 |
| 筛选 | 出处与标签各可选一个；可与搜索同时使用；可一键清除 |
| 筛选状态 | 存在网址的 search params（`?sourceId=&tagId=&q=`），重新整理后保留 |
| 新增出处 | 在名句表单里完成，储存名句时一并建立 |
| 新增标签 | 输入不存在的名称时，储存名句时一并建立 |
| 删除 | 需要再点一次确认 |
| 验证 | 句子内容与出处必填；新增出处时名称必填 |
| 空状态 | 没有资料、或筛选后没有结果时，显示提示 |

## 三个版面设计

| 设计 | branch | 版面 | 新增 / 编辑 |
| --- | --- | --- | --- |
| A. 三栏式 | `design/three-column` | 左：出处 / 标签筛选；中：搜索 + 名句列表；右：选中名句的详细 | 在右栏显示表单 |
| B. 侧栏 + 卡片网格 | `design/card-grid` | 左：出处 / 标签筛选；右：搜索 + 多栏卡片（masonry）铺满屏幕 | 弹出对话框 |
| C. 置中单栏 | `design/centered` | 内容置中约 960px；搜索与筛选在列表上方 | 独立页面（`/quotes/new`、`/quotes/$quoteId/edit`） |

三个设计共用同一套假数据、资料操作与表单字段，差别只在版面与表单出现的方式。

## 技术限制
- 样式用 Tailwind CSS；UI 组件用 shadcn/ui（第二轮加入）。
- 遵守 [coding-style.md](../../../coding-style.md)。

## 第二轮（选定 A. 三栏式之后）

| 项目 | 规则 |
| --- | --- |
| 版面 | 沿用三栏式 |
| 列表显示 | 中间列表可切换 **row**（一行一句）与 **grid**（多栏卡片）；预设 row，选择记在浏览器（localStorage） |
| Dark mode | 支援浅色 / 深色；**预设跟随系统主题**，可在左上角选单改成浅色、深色或跟随系统；选择记在浏览器 |
| 表单 | 用 React Hook Form 管理表单状态，zod 定义验证规则（必填规则与第一轮相同） |
| UI 组件 | shadcn/ui，primitive 用 **Base UI**（不是 Radix） |
| `cn` | 用 shadcn 提供的 `cn` 包（引擎来自 cnfast），取代 clsx + tailwind-merge |

验收：
- [x] row / grid 切换正常，重新整理后保留
- [x] 系统为深色时预设显示深色（防闪白靠 `index.html` 的脚本，未做量测）
- [x] 主题选单可切换浅色 / 深色 / 跟随系统；选深色后重新整理会保留
- [x] 表单验证错误显示在字段下方；新增（含新出处、新标签）、编辑、删除都正常
- [x] 你在实际屏幕上确认外观

## 第三轮：新增改用 dialog

| 项目 | 规则 |
| --- | --- |
| 新增 | 按「新增名句」弹出 dialog，右栏保持原本正在读的句子 |
| 储存后 | 关闭 dialog，新句子出现在列表；右栏不切换 |
| 关闭 | 「取消」或 Esc；点 dialog 外面**不**关闭，避免误触丢掉写到一半的内容 |
| 编辑 | 照旧在右栏 |

验收：
- [x] 打开、储存、取消 dialog 时，右栏内容都不变
- [x] 验证错误、新出处、新标签在 dialog 里正常
- [x] 重新打开是空白表单
- [x] 你在实际屏幕上确认
