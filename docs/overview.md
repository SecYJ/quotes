# 项目概览：Lines（个人名句记录网站）

## 这是什么
一个公开的网站，用来记录从戏剧、书、现实生活或其他地方听到的名句，每一句都会记下出处。版面像一份晚报的副刊。

## 使用情境
- 看剧、读书、跟朋友聊天时听到一句好话，之后把它写进资料档、push，网站就更新了。
- 之后可以回头翻看：看某部剧记过的所有句子、某个主题的句子，或用关键字找回某一句。
- 任何人都可以浏览名句，不需要注册或登入；筛选后的网址可以直接分享。
- 手机、平板、桌机都能看。

## 记录的内容
每一句名句包含：
- **句子内容**（必填）
- **谁说的**（选填）
- **出处**：来自哪部剧、哪本书，或现实生活中的哪个场合（例如"朋友聊天"）。出处分为戏剧、书、现实生活、其他四类，一个出处可以记很多句。
- **出处细节**（选填）：例如第几集、哪个场合
- **个人笔记**（选填）
- **标签**（至少一个）：可以加多个，用来分类
- **收录日期**：决定排序，最新的在最前面

## 功能
1. 浏览所有名句，最新一句放最大。
2. 按出处筛选，例如查看某部剧的所有句子。
3. 按标签筛选，可以和出处一起用。
4. 用关键字搜索句子内容和说话人。
5. 筛选结果有自己的网址，可以分享。

只做以上功能，其他功能不在范围内。
