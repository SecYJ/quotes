# 项目概览：Lines（个人名句记录 App）

## 这是什么
一个公开的网站，用来记录从戏剧、书、现实生活或其他地方听到的名句，每一句都会记下出处。

## 使用情境
- 看剧、读书、跟朋友聊天时听到一句好话，回到电脑前把它记下来。目前只支援 **desktop**（34 吋带鱼屏，3440×1440）。
- 之后可以回头翻看：看某部剧记过的所有句子、某个主题的句子，或用关键字找回某一句。
- 任何人都可以浏览名句，不需要注册或登入。
- 只有我能新增、编辑、删除名句，这些功能放在独立的管理页面。

## 记录的内容
每一句名句包含：
- **句子内容**（必填）
- **谁说的**（选填）
- **出处**：来自哪部剧、哪本书，或现实生活中的哪个场合（例如"朋友聊天"）。出处分为戏剧、书、现实生活、其他四类，一个出处可以记很多句。
- **出处细节**（选填）：例如第几集、哪个场合
- **个人笔记**（选填）
- **标签**：可以加多个，用来分类

## 第一版功能
1. 在管理页面新增、编辑、删除名句；新增时可以选已有的出处，也可以当场新增出处。
2. 按出处筛选，例如查看某部剧的所有句子。
3. 用标签分类，并按标签筛选。
4. 用关键字搜索句子内容和说话的人。

第一版只做以上功能，其他功能不在这次范围内。
